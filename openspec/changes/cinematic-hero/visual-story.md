# Visual Story — cinematic hero

Status: APPROVED by owner. Decisions: 28 s, credit cap 400, Wan 3.0 first (Seedance 2.5 fallback), shot 5 without overlay.

## Concept

One continuous first-person camera move through an abstract production system: a blueprint becomes a running system, then pulls back to show the whole thing. Non-photoreal, flat and architectural, in the site's own language: warm off-white `#fafaf7` ground, 24px dot grid, coral `#d97757` as the only accent, soft ambient light.

Hard content rules for every frame: no text, numbers, labels, logos, real brands, people, faces or hands. All words are HTML overlays.

## Film length and scroll pacing

- Film: 7 shots x 4 s = **28 s**, 16:9, 1080p master.
- Scroll: pinned stage with **7 viewport-heights of travel** (wrapper = 8vh: 1vh stage + 7vh travel). Mapping is linear (0.25 vh per second), so each shot owns exactly 1 viewport-height of scroll and 1/7 of progress.
- Mobile uses the same film cropped by `object-fit: cover`. Action is composed inside the **center ~56% of the frame width** so the portrait crop never cuts the subject.

## Risks specific to this story

- **All-intra budget:** the desktop file must be <= 8 MB for 28 s, about 2.3 Mbps, which is tight for all-intra 1080p. The content is flat and low-detail, which helps. If it does not fit, the desktop encode drops to 1280x720 or the film shortens to about 20 s. A budget probe on the first clip (task 6 moved earlier as a probe) will tell us before the rest is generated.
- **Continuity at clip boundaries:** chaining by last frame can still drift in style. Frame-by-frame QA at each boundary is mandatory.
- **Abstract can look generic:** this is why the gate exists. If the establishing still is not distinctive, we stop before any video credits are spent.
